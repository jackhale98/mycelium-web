#+title: Evergreen notes
#+filetags: :pkm:writing:

Evergreen notes are written and organised to evolve, accumulate and
contribute across projects. They're the long-lived descendants of the
[[id:3c9d7e10-2f4b-4a8e-b1c6-7d8e9f0a1b02][Zettelkasten]].

* Evergreen notes should be
- [X] Atomic
- [X] Concept-oriented
- [X] Densely linked
- [ ] Written for your future self

* Compounding
Like a [[id:8f3a2c1e-6b4d-4e2a-9c7f-1a2b3c4d5e01][fungal network]], the payoff is superlinear: each new note can connect
to every note before it. Pair this with [[id:4f5a6b70-8c9d-4e0f-a1b2-c3d4e5f6a707][Spaced repetition]] so the network
stays alive in your head, not just on disk.

Writing them in Org mode inside Emacs makes linking nearly free: a link is
just the note's ID, so renaming a note never breaks one.
