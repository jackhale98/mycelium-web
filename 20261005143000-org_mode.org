#+title: Org mode
#+filetags: :emacs:tools:

Org is a plain-text format for notes, outlines, tasks and literate
programming. Everything here is just text — which is why it ages so well.

* Markup cheat sheet
:PROPERTIES:
:ID:       6c7d8e90-0a1b-4c2d-9e3f-4a5b6c7d8e09
:END:
*bold*, /italic/, _underline_, +strike-through+, =verbatim= and ~code~.

Links look like =[[id:...][description]]= and timestamps like <2026-10-20 Tue>.

* Agenda workflow
:PROPERTIES:
:ID:       6c7d8e90-0a1b-4c2d-9e3f-4a5b6c7d8e10
:END:
Tasks anywhere in the vault show up in the agenda:
- =TODO= → =NEXT= → =DONE=
- =SCHEDULED= for when to start, =DEADLINE= for when it's due
- Repeaters like =+1w= keep habits on the agenda

Built on [[id:1e2f3a40-5b6c-4d7e-8f9a-0b1c2d3e4f11][Emacs]], but [[id:a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c12][Mycelium Web]] reads the same files.
